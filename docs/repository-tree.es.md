GraphLive 1.1.1 · 14 de octubre de 2026. El [mapa principal](repository-tree.md) describe las carpetas actuales: app contiene rutas, packages los módulos internos, public los recursos, tests las pruebas, scripts las herramientas, docs la documentación y releases las notas de versión.

No se incluyen dependencias instaladas, builds, datos privados, entorno ni notas locales. Usa `git ls-files` para obtener el inventario completo.
